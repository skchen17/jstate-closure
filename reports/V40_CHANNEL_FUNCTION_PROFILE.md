# V40 — Channel Function Profile

Status: **design sealed; intervention outcomes not run**.

For each externally labelled natural token fork, the frozen condition map is BASE, REC-only, Conv-only, KV-only, REC+Conv, and REC+Conv+KV. The recipient/donor pair differs in one encoded token, and labels are fixed by the task generator. The proposed primary comparison is recovery of the donor versus recipient task variable after native cache-channel exchange, not donor-response cosine. Donor-vector fidelity is secondary.

No task-variable recovery rate or channel specialization is currently established. Before formal development execution, an append-only execution design must specify answer-token scoring, exact native writeback/equality checks, and the surface-only, irrelevant-history, same-prefix-mismatch, shuffled-state, KV, Conv, and REC controls. Calibration may test feasibility; validation and independent final must not tune this design.
